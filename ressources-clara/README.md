# Ressources de Clara

Déposez ici les fichiers fournis par Clara. Ils servent de source ; le site utilise des versions optimisées.

- `logo/` : le logotype en SVG, une couleur.
- `typos/` : Readex Pro (TTF) et, si besoin, Poppins.
- `projets/<nom-du-projet>/` : couverture et images du projet, 2400 px de large au minimum, JPG ou PNG sRGB.
- `portrait/` : photo de Clara (facultatif).
